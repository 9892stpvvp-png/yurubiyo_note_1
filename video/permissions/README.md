# 動画素材・利用許可の管理

更新日：2026-10-06（日本時間）

案件登録とは別に、このフォルダで商品・素材の利用条件と対応状況を管理する。

## 許可の状態

- unconfirmed：許可未確認
- awaiting_reply：問い合わせ済み・回答待ち
- allowed：根拠と対象素材、SNS、加工条件を確認した許可済み
- denied：利用不可

指摘がないことは許可の根拠として扱わない。問い合わせ済みの案件は回答待ちを維持する。
公開するというオーナーの判断と、権利者・広告主の利用許可を区別する。
既存の eligibleForAutomaticVideo は許可条件を確認するまで false を維持する。

## 公開と指摘の管理

公開状況は許可状態と別に記録する。公開報告がない案件を公開済みにしない。

公開時に残す情報：
- プログラムID、素材URLまたは素材ID
- 動画ファイル名・版、掲載SNS、投稿URL、公開日
- 許可状態と公開判断の記録

指摘を受けた場合：
1. 指摘の原文、受信日、対象素材、対象投稿URLを記録する。
2. 対象素材の運用状態を利用停止にし、新しい動画生成・再投稿の候補から外す。
3. 同じ素材を使った動画と公開先を確認する。
4. 要求に応じて削除・修正し、対応日と結果を残す。修正を求められた場合は指定条件に従う。
5. 再利用は、指摘の解消と利用条件を確認してから判断する。

指摘のない公開動画は対応状況「指摘なし」で管理するが、許可未確認を許可済みに変更しない。
削除・修正によって提携解除や成果否認が必ず避けられるとは扱わない。
